# InspectX 3D World Simulator

Inspection-centric digital twin for drone visual inspection of a Gamesa G97 2.0 MW turbine locked in the Y-position (REU_CQ_SOP_WT_001 R1).

Features: drone/camera platform registry (InspectX + SIYI ZR10, DJI Mini 4 Pro), environment and lighting setup, pre-inspection risk questionnaire with automated advisories, fixed/adaptive mission zoom with per-waypoint overrides, configurable blade defect library, simulated AI detection with bounding boxes, ground-station dashboard (notifications, JSON packages, heatmap, review queue), CompliQ image-quality scoring, storage planning and a lightweight wake/turbulence model.

Static single page: open `index.html`; no build step.
